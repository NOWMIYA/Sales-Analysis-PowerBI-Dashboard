# Sales Analysis Dashboard – Power BI
An interactive Sales Analysis Dashboard created using Microsoft Power BI to analyze sales, profit, cost, products, regions, and sales channels.

##Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

##Dashboard Overview
This dashboard provides insights into:
- Sales performance by region
- Profit by sales channel
- Product performance
- Cost price analysis
- Sales distribution
- Regional performance
- Category and product analysis

## Project Objective
The objective of this project is to transform sales data into an interactive Power BI dashboard that helps analyze business performance and identify useful sales and profit insights.
